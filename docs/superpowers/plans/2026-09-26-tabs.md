# Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить составной Tabs для React в трёх слоях Dreadnought, с доступной клавиатурной навигацией и стандартным оформлением.

**Architecture:** `core` вычисляет следующий доступный `value`; React-адаптер владеет состоянием, DOM, фокусом и ARIA; `ui/react` накладывает CSS Modules и тему на те же части адаптера. Публичные точки входа остаются агрегированными.

**Tech Stack:** TypeScript 5.7, React 19, CSS Modules, CSS custom properties, Vitest 3, Testing Library, Storybook 10, pnpm 9.6.

**Spec:** `docs/superpowers/specs/2026-09-26-tabs-design.md`

## Global Constraints

- Первая версия — горизонтальные вкладки с заранее доступными панелями; стрелки выбирают вкладку сразу.
- API: `Tabs`, `Tabs.List`, `Tabs.Tab`, `Tabs.Panel`; обязательны ровно один из `value` и `defaultValue`, совпадающие непустые строковые значения вкладок и панелей.
- `core` не зависит от React, DOM и CSS; слой 2 не импортирует слой 3; CSS только в слое 3.
- Неактивные панели остаются в DOM с `hidden`; `disabled` нельзя выбрать; фокус и ARIA соответствуют WAI-ARIA Tabs Pattern.
- Семейство `Navigation/Tabs` повторяется в `src/` и зеркальном `tests/`; компонентные имена PascalCase, функции/хуки camelCase, локальные `index.ts`.
- Сохранять пользовательское удаление `packages/core/src/behaviors/.keep`; не включать его в коммиты.

## Review Focus

1. Значение вкладки с пробелом, `%` или кириллицей → стабильные и уникальные HTML ID; тест в Task 2.
2. Смена `value` родителем без события пользователя → панель меняется, `onValueChange` не вызывается; тест в Task 2.
3. Все вкладки `disabled` → чистая функция возвращает `undefined` без ошибки; тест в Task 1. В React выбранная вкладка обязана быть доступной по публичному контракту.
4. Вкладки внутри формы → клик не отправляет форму; тест в Task 2.
5. Неактивная панель с внутренним состоянием → переключение не размонтирует её; тест в Task 2.

**Interfaces:** Produces `TabItem = { value: string; disabled?: boolean }`, `TabDirection = 'previous' | 'next' | 'first' | 'last'`, `getNextTabValue(tabs: readonly TabItem[], currentValue: string, direction: TabDirection): string | undefined`. `TabsCore` is the framework-independent contract `{ value: string; tabs: readonly TabItem[] }`.

```ts

expect(getNextTabValue(tabs, 'c', 'next')).toBe('a');
```

- [ ] **Step 2: Run** `pnpm exec vitest run packages/core/tests/components/Navigation/Tabs/getNextTabValue.test.ts`; expect failure because the module does not exist.
- [ ] **Step 3: Implement** a pure function. Filter enabled entries, return `undefined` if empty; first/last pick boundary, next/previous use the current index modulo enabled length. If current is absent, next chooses first and previous chooses last. Add exact exports to local and component indices.

```ts
export function getNextTabValue(tabs: readonly TabItem[], currentValue: string, direction: TabDirection): string | undefined {
  const enabled = tabs.filter((tab) => !tab.disabled);
  if (enabled.length === 0) return undefined;
  if (direction === 'first') return enabled[0]!.value;
  if (direction === 'last') return enabled.at(-1)!.value;
  const index = enabled.findIndex((tab) => tab.value === currentValue);
  if (index < 0) return direction === 'next' ? enabled[0]!.value : enabled.at(-1)!.value;
  const offset = direction === 'next' ? 1 : -1;
  return enabled[(index + offset + enabled.length) % enabled.length]!.value;
}
```

- [ ] **Step 4: Run** the test, `pnpm --filter @dreadnought/core typecheck`, and `pnpm --filter @dreadnought/core build`; expect all pass.
- [ ] **Step 5: Commit** only this task's files as `feat(core): add Tabs navigation contract`.
