# Card

`Card` — оформленный контейнер для произвольного содержимого. В отличие от интерактивных компонентов, он не добавляет собственного поведения и не требует логики в `core`.

```tsx
import { Card } from '@dreadnought/ui/react';

<Card>
  <h3>Три слоя</h3>
  <p>Можно выбрать готовый компонент или собрать свой на логике библиотеки.</p>
</Card>
```

`Card` выводит обычный `div` и принимает его стандартные свойства, `ref`, `className` и любые дочерние элементы. Карточка сама не становится ссылкой или кнопкой: интерактивные элементы размещаются внутри неё. Для осмысленного заголовка используйте обычный HTML-заголовок внутри карточки; её оформление не меняет типографику содержимого.

`CardAdapter` из `@dreadnought/react/unstyled` даёт тот же контейнер без библиотечных стилей. Готовый `Card` использует токены `--dreadnought-card-bg`, `--dreadnought-card-padding` и `--dreadnought-card-radius`. Их можно задать для темы или локально через собственный класс. Для полностью другой разметки используйте обычный HTML и, при необходимости, карту классов `cardPresentation` из `@dreadnought/ui`; при ручном применении карты подключите `@dreadnought/ui/style.css` и тему.
